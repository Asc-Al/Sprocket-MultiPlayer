Sprocket Multiplayer 1.0.0
Мультиплеер для Sprocket на BepInEx 6 (IL2CPP) и LiteNetLib.

- Установка:
Распаковать в корневую папку, рядом с Sprocket.exe, после запустить (см. примечания).
ВТОРЫМ ШАГОМ - удалить из папки игры папки BepInEx и dotnet, а также файлы winhttp.dll, doorstop_config.ini и .doorstop_version.
(они нужны для установки мода)

- Примечания:
Первый запуск может быть долгим
Обязательно иметь одинаковые версии мода и игры (изначально мод создавался под версию игры 0.2.55.5, могут быть баги на других версиях)
Нужно играть через Radmin VPN/ZeroTier, либо же через открытый 27015 UDP-порт.

- Функции:
Игра по сети через подключение по IP;
Лобби находится в "Custom Battle" в пункте "Игра", можно выбрать одиночную игру или по сети;
Каждый может добавить свой танк и выбрать (кликом), а так же убрать (двойным кликом);
Команда меняется кнопкой с двойной стрелкой, ник меняется кликом по нему в списке игроков.
В бою синхронизируются движение, башни, выстрелы и урон, над союзниками видны ники, по F8 открывается чат в матче.

- Сборка из исходников (для разработчиков):
Нужен .NET SDK 6 или новее, после этого требуется один раз запустить игру с модом, чтобы появилась папка BepInEx/interop, после собрать проекты:
dotnet build SprocketMP/SprocketMP.csproj -c Release -p:GameDir="<папка игры>"
dotnet build Loader/Loader.csproj -c Release -p:GameDir="<папка игры>"
dotnet build InteropFix/InteropFix.csproj -c Release -p:GameDir="<папка игры>"
